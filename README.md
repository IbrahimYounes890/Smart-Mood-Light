# Smart-Mood-Light
This mood light will automatically change brightness based on the light in the room using  a photodetector and/or manually adjust the intensity and  colour.

# Description:
It is a lamp lit by addressable LEDs that changes brightness level based on the light level in the room. It reads data from a photodetector and then converts the data into a light level. It is made up of 4 3D-printed pieces. 
* Two base pieces that come apart to provide space for the electrical components.
* A middle post to wrap the LED strip around.
* An aesthetic vase-like enclosure to diffuse the light.

# Parts used:
* XIAO ESP32 S3
* GL5528 5mm LDR sensor
* Addressable LED Strip
* USB-C cable and old phone brick
